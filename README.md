# Roomie｜合租生活管家

> 把模糊的人情协商，转化为透明、轻量、可调整的共同规则。

**合租，也合得来。** *Live together. Make room for each other.*

Roomie 面向年轻合租人群，回应四类高频痛点：**费用分摊不清、清洁责任混乱、公共物品无人管理、共同规则难达成**。

但它**不是**「记账 + 值日 + 库存 + 公约」四个 CRUD 工具的简单集合，而是一个**共同生活的中立协调者**。

---

## 核心特色：Roomie Coordination Agent

这是 Roomie 最关键的差异化能力。大多数工具只做「记录」——记一笔账、排一次班；Roomie 在记录之上，还能**理解一次生活事件对多个模块的连锁影响**，并帮室友形成一份公平的调整方案。

工作机制是一条完整闭环：

```
识别事件 → 理解影响 → 生成方案 → 室友确认 → 执行修改
```

**AI 不替室友做决定，而是降低大家达成共识的成本。**

首页的 AI Insight 卡片就是一个完整演示：

> Mia 将在 9 月 15–25 日出差 10 天。Roomie 识别出这会同时影响 **1 次值日** 和 **1 笔公共费用**，并给出两项调整建议：
>
> - 🧹 **清洁**：把 Mia 9 月 18 日的浴室清洁，与 Alex 9 月 28 日的任务互换——每个人总工作量保持不变。
> - 💰 **电费**：从「三人均分」改为「按在家天数分摊」（Jenny 30 天 / Alex 30 天 / Mia 20 天），并自动重算每人应承担金额。
>
> 所有调整只有在室友点下「确认」后才同步生效，且对所有人透明可见。

## 三个产品原则

整个产品围绕三个关键词展开：

| 原则 | 含义 |
|------|------|
| **Responsibility** · 责任明确 | 每笔费用、每项清洁、每个公共物品，都明确负责人与参与人 |
| **Transparency** · 共同透明 | 费用、任务、库存、规则都有共享记录，减少「我记得不是这样」的争议 |
| **Consensus** · 共同协商 | 情况变化时，由 Roomie 识别影响、提出方案，经室友确认后执行 |

重点不是「管理室友」，而是「降低共同生活中的沟通与协商成本」。

## 功能一览

**Home｜首页 Dashboard**
回答「今天这个家有什么需要我处理」，而不是堆四个入口。今日待办、AI 洞察卡片、合租状态、最近动态一屏看清。

**Expenses｜费用 AA**
公共账本：谁垫付、谁该承担一眼说清；支持平均分摊、按在家天数、自定义比例三种方式。

**Chores｜清洁轮值**
自动轮值（当前 → 下一轮），每项任务有负责人、截止时间与状态，完成即进入最近动态。

**Supplies｜公共物品**
库存消耗可视化，低库存自动识别并提醒对应负责人，在真正用完之前找到正确的人。

**Rules｜室友公约**
每条公约是独立卡片，支持发起变更、室友表决（2/3 同意生效）——规则由室友共同形成，而非单方制定。

**Ask Roomie｜自然语言入口**
全局 AI 输入，统一走「理解 → 预览 → 确认 → 执行」四步；涉及多人共同事务必须先确认再执行。
